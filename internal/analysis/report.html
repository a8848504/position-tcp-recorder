分析口径

  • 理论应收 = floor((本设备末次收到 − 首次收到) / 理论周期) + 1；间隔超过理论周期的 1.5 倍列为待排查。
  • TCP 按序号重组，重复载荷只计算一次。缺口前后独立拆帧，原始文件、回放文件和录制状态均不改写。重组后没有缺口不能证明无线链路没有缺报。
  • L、C、TA、R 参照当前定位源码拆分；TO/01/24 与 C/0x28 为样本结构推断，长度、帧尾与校验和均验证，字段语义待硬件协议确认。
  • C 的包号位置来自源码；TA/TO 的计数器位置由样本推断。“未见序号数”假设每次发送加一、未重置、相邻上报未跨完整 256 个序号，不是确认的无线或 TCP 丢包率。
  • 同一设备经不同网关或不同协议上报会分别统计；未尝试把多网关重复广播合并成一次真实发送。
  • 抓包从中途开始可能缺少登录；服务器收到数据也不代表定位计算、入库成功。要确定原因需核对硬件发送、网关接收及服务端处理日志。
  • 图表每组最多约 5,000 个抽样点；所有统计、CSV 和最长空档使用全量数据。支持最多 1,000,000 条有效内帧与 4,096 条 TCP 流，超过时明确终止。
